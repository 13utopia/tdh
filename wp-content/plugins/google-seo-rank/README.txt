== Description ==
Google Rank is a powerful SEO tool for WordPress designed to enhance your website's visibility on Google.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/google-rank` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
